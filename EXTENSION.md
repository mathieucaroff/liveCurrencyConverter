# Extension informations

## Extension Name

YEN to EURO auto converter

## Description

Detect prices expressed in YEN and converts them to EURO by applying the current conversion rate. The detection use the patterns "¥", "YEN" and "JPY". The rates come from exchangerate-api.com.
